5-Step Universal Oncall Workflow

Muscle memory: 1 → 1.5 → 2 → 3 → 4 → 5.

  1. 1

    Read the alert (don't query yet)

    Grab severity / cluster / namespace / ts / client / metric + threshold. Stop if any field is missing. Compute window: ts ± 3min (widen 2× if rule eval interval > 5min).

  2. 1.5

    Click the alert's source URL (orange)

    Drops you straight into vmui with the current value; pull window to 24h to check if it's chronic noise.

  3. 2

    Open the funnel-top dashboard

    Decided by alertname (see routing table on Slide 8).

  4. 3

    Bisect on the SLA dashboard using the 4 quadrants

    Order: panel 192/359 → 371 → 373 → 194.

  5. 4

    Drill into logs

    Window ±3min, use a time-pinned link.

  6. 5

    Write one-sentence hypothesis → one query to verify → then act (teal)

    Any K8s mutating op must be prefixed with # INTENT:.
