# 日本高度人才 IT 资格加分：能加分的证书清单 + 高性价比选证建议

**调研日期**：2026-07-13
**调研对象**：日本「高度専門職（高度人材ポイント制）」中 IT 资格加分项
**目标人物画像**：中国籍工程师，现职 SRE，前 SDE，CS 科班。已在日工作。
**核心诉求**：(1) 哪些 IT 证书能加分/不能加分（官方证据）；(2) 对我的知识储备最高性价比的证书（难度适中 + 契合 SE 技能，少复习基础）；(3) 重点 2 个 + 备用 + 各自考察内容 + 选择理由。
**调研方法**：4 路 subagent 并行（官方告示清单 / IPA 试验难度 / 中国软考互认 / 实战经验坑点），维度间 ≥50% overlap 交叉验证。

---

## TL;DR — 一句话结论

> **规则：持 1 张认可的 IT 资格 = +5，持 2 张及以上 = +10（封顶 10，第 3 张起不再加分）。分数与证书难度无关——一张最基础的 FE 和一张最难的高度试验，都只算 +5。所以「性价比」= 用最省力的方式凑满 2 张。**
>
> **对你（中国籍 SRE）最优解只有两条路，取决于一个问题——能否方便回中国大陆考试（每年 5 月 / 11 月两次）：**
>
> - **能回国考 → 首选中国软考两张中级**：`网络工程师 + 数据库系统工程师`。中文考、无作文、正好命中 SRE 核心、被日本官方认可为**等同其高度试验**（网络工程师↔ネットワークスペシャリスト、数据库↔データベーススペシャリスト）。这是"中级难度换高度资格"的套利，最省力。
> - **只能/更想在日本考 → 首选 IPA 两张**：`応用情報技術者(AP) + 情報処理安全確保支援士(SC)`。在日本就能考、均**无长篇日语论文**、AP 从 2026 起 CBT 通年可考、SC 一年两考且合格率最高、内容契合 SRE（安全 / 事件响应）。
>
> **明确不能加分（已官方证伪）**：`ITパスポート`、以及 **AWS / Kubernetes(CKA) / Cisco(CCNA/CCNP) / Red Hat(RHCE) / CompTIA / PMP` 等一切厂商 / 国际认证。别浪费时间。

## Task 1：哪些能加分、哪些不能（附官方证据）

### 1.1 加分规则（法条级确认）

依据《出入国管理及び難民認定法別表第一の二の表の高度専門職の項の下欄の基準を定める省令》（平成26年法務省令第37号），"資格"项配点：

> - 法務大臣が告示をもって定める情報処理技術に関する試験のうち、**二以上に合格** → **10 ポイント**
> - いずれか一 → **5 ポイント**（最大 10 ポイント）

- 出入国在留管理庁 配点省令 PDF：https://www.moj.go.jp/isa/content/930001658.pdf
- IPA 官方同规则表述：「5ポイント（**2以上の試験に合格又は資格を取得している場合は10ポイント**）（最大10ポイント）」 https://www.ipa.go.jp/shiken/asia/mutual-recognition/about.html

**要点**：上限 10 分，只认前 2 张；考第 3、4 张不再加分。「软考 + IPA 混搭」两张同样算数（都在告示清单内）。

### 1.2 认可清单叫「IT 告示」，是一份封闭逐条清单

正式名：《…技術・人文知識・国際業務の在留資格に係る基準の特例を定める件》（平成13年法務省告示579号，历经平成25年437号大扩充、平成26年574号）。它只收两类：**(a) 日本 IPA 情報処理技術者試験**，和 **(b) 与日本有政府间相互认证的 11 个国家/地区的国家级考试**。厂商私有认证在立法结构上就被排除。

## Task 2：性价比分析（结合你的 SRE / 前 SDE / CS 背景）

### 2.1 三个决定性洞察

1. **分数与难度脱钩** → 目标是"用最省力方式凑 2 张"，不是"考最难的"。含金量是次要目标，除非你另有职业诉求。
2. **软考中级 = 日本高度资格的套利**：官方把软考中级（网络工程师 / 数据库系统工程师）认作等同日本レベル4高度试验。你只需通过**中级难度 + 中文 + 无作文**的考试，就拿到被认可的"高度级"资格。对中国籍工程师这是全场最高性价比的杠杆。
3. **两条路径的真正取舍是"考点位置 vs 考试语言"**：
   - 软考：零日语负担、契合、但**必须回中国大陆考**（每年仅 5 月 / 11 月两次，且必须一次性通过全部科目）。
   - IPA：在日本就能考、但用日语（好在推荐的几张**都没有长篇论文**，只需读案例 + 写几十字短答）。

### 2.2 你要避开的"基础复习陷阱"如何被绕过

你明确不想为二进制 / 进制 / 逻辑电路 / 基础算法额外复习。数据显示这些**只出现在**：
- IPA 各高度试验的「午前 I」——但持 AP 或任一高度合格后，**2 年内可申请免除午前 I**（https://www.nw-siken.com/nwkeisiki.html）。
- IPA 的 FE「科目 B」（算法 / 伪代码占 8 成）——这是 FE 性价比低的原因之一。
- IPA 的 ES「午前 II」（25 题中约 13 题硬件电路：逻辑电路 / A-D 转换 / 运放）——ES 因此是全场最该避开的。

**推荐路径均已绕开**：软考中级重点在本专业（网络 / 数据库）；IPA 走 AP（午前基础可"过去问流用"低成本刷过）→ 之后免除高度午前 I，各高度午前 II 只考本专业、不考底层电路。

## Task 3：重点推荐 2 个 + 备用 + 考察内容 + 理由

### 🥇 首选路径 A（能回国考）：中国软考两张中级

#### ① 网络工程师（中级）
**考察内容**
- **上午·综合知识（客观题）**：计算机网络与 OSI/TCP-IP、以太网 / 交换 / VLAN、IP 编址与子网划分、路由协议（RIP/OSPF/BGP）、网络安全（防火墙 / ACL / IPSec / TLS）、DNS/DHCP/HTTP、无线网络、网络管理与规划设计。
- **下午·网络系统设计与管理（填空 / 简答）**：实际配置与排障——子网规划、路由/交换配置、防火墙策略、DNS/DHCP 部署、故障定位、网络设计题。
- **SRE 契合**：网络排障、负载均衡、DNS、TLS、连通性诊断正是你日常。

#### ② 数据库系统工程师（中级）
**考察内容**
- **上午·综合知识**：数据库原理与关系代数、SQL、规范化（1NF~BCNF）、事务 / 并发控制 / 隔离级别 / 恢复、索引与查询优化、ER 建模、数据仓库、分布式数据库基础。
- **下午·案例分析**：ER 建模、SQL 编写、规范化分解、事务与锁、性能调优实战题。
- **SRE 契合**：DB 性能 / 慢查询 / 复制一致性 / 备份恢复，与运维强重合。

**软考通用事实**：一年两次（5 月 / 11 月）；2023 下半年起全面机考；中级考 2 科（综合 + 案例），**须一次性全部达 60%**；报名零门槛（不限学历专业）；**仅中国大陆设考点**；证书**永久有效**。

### 🥈 首选路径 B（在日本考）：IPA 两张

#### ① 応用情報技術者（AP）—— 打底
**考察内容**
- **午前（80 题四択）**：テクノロジ（基础理论少量 + 算法 + DB + 网络 + 安全 + 系统构成）+ マネジメント + ストラテジ。**过去问流用率高，刷题即可低成本过**。
- **午後（150 分，11 选 5，記述式 30–50 字短答，非作文）**：安全为必答，其余可从网络 / DB / 编程 / 系统架构 / 项目管理 / 服务管理等中选 4——**可全选技术题、避开管理题**。
- **理由**：技术全面契合、无长论文、日语负担仅短答；**考过后 2 年内免除各高度试验午前 I**（一劳永逸绕开二进制 / 电路基础）。2026 起 CBT 通年可考。

#### ② 情報処理安全確保支援士（SC）—— 第二张
**考察内容**
- **午前 II（25 题四択）**：以信息安全为主 + 少量网络 / DB。
- **午後（150 分，記述式，4 选 2）**：实务案例——事件响应（incident response）、漏洞与加固、加密 / 认证、安全编程、网络安全、恶意软件应对；日语短答记述，**无长篇论文**。
- **理由**：内容 = SRE / oncall 日常（安全、事件响应）；**一年两考（春 + 秋）、机会最多、合格率最高（~20%）**。
- ⚠️ **一个需确认点**：SC 现为名称独占国家资格，"取得资格"需考试合格 + 付费**登録**（登録費 + 每 3 年讲习费）。用于**签证加分应以"試験合格"即计入**（无需付费登録），但建议向行政书士确认；若想完全避开此细节，用下方 **NW 或 DB** 替换即可（纯试验、无登録问题）。

### 🥉 备用清单（按场景挑）
- **偏 SDE 想换软考里一张** → **软件设计师（中级）**：考数据结构 / 算法 / 面向对象 / UML / 设计模式 / 软件工程，中文，对 CS 科班友好。
- **想要纯日本高度证、避开 SC 登録细节** → **ネットワークスペシャリスト(NW)** 或 **データベーススペシャリスト(DB)**：均记述式无论文、契合 SRE，DB 合格率略高、一年 1 考。
- **愿投入且追求含金量 / 签证观感** → **プロジェクトマネージャ(PM)** 或 **システム監査技術者(AU)**：有 2200–3600 字论文，但**2026 起论文改键盘打字**，非母语者手写汉字的最大障碍消失，2026–2027 是难得窗口（2028 后论述形式可能被砍）。AU 的"风险识别→评估→控制验证"思维与 SRE 可靠性工程相当契合。

### 为什么"这两条路径的头两张"是最优选择

1. **精准命中你的两条标准**：
   - *难度适中*——软考走中级（非初级程序员、非带论文的高级）；IPA 走 AP(Lv3) + SC(Lv4 但无论文)。都不碰"要复习二进制/电路"的坑（软考中级聚焦本专业；IPA 靠 AP 免除午前 I）。
   - *契合度高*——网络 / 数据库 / 安全 / 事件响应全部是 SRE 日常，你几乎"以考带练"，额外复习量最小。
2. **省力最大化**：软考是中文 + 无作文（对中国 CS 科班可能接近裸考或 30–50h）；IPA 推荐项全部无长篇论文，只需日语短答。全场最省力的凑 +10 组合就在这里。
3. **规避了所有低性价比项**：FE 太基础、ES 硬件电路 + 论文双雷、ST 离工程最远 + 日语负担最重、高级软考要写论文——都被排除；厂商证根本不算。
4. **决策只剩一个变量**：能否方便回中国大陆考（时间卡 5 月 / 11 月）。能→软考完胜（更省力）；不能→IPA 兜底（更方便）。两条都稳拿 +10。

## 实操坑点与行动清单

**坑点（多来源交叉验证）**
1. **ITパスポート 不加分**；**AWS / CKA / Cisco / RHCE / CompTIA / PMP 不加分**——反复确认，别踩。
2. **提交材料**：只需**合格证明书复印件 + 日语译文**（译文注明译者姓名 / 联系方式）；**无需公证 / 使馆认证 / CCPIT**（日本入管官方 + 多家行政书士一致）。软考科目名建议用告示原文日文名（如"軟件設計師（ソフトウェア設計エンジニア）"）避免审查困惑。
   - 官方须知：https://www.moj.go.jp/isa/applications/status/designatedactivities02_00004.html
3. **证书有效期**：软考证书、IPA 合格均**永久有效**；但告示会随时改定，**以申请时点最新告示为准**（个别老试验会被移出）。
4. **业务关联性**：IT 告示资格是否需与本职相关，来源略有出入（visa365jp 称不需要；个别行政书士称需要）——你 SRE/SDE 天然满足，保守选与本职相关的即可。
5. **加分体现时点**：在留资格申请 / 变更 / 更新，或永住申请时，按点数表自评 + 附证明。
6. **软考须在中国大陆考**：若已在日本，规划好回国窗口（5 月 / 11 月各考一张，一年内集齐两证）；否则直接走 IPA 更省事。

**建议行动顺序**
1. 先确认自己**能否在半年内回国参加软考**（这决定走 A 还是 B）。
2. 走 A：报名 5 月与 11 月各一门中级（网络工程师 + 数据库系统工程师），中文以考带练。
3. 走 B：先考 AP（2026 CBT 通年）拿到手 + 免除午前 I；再在最近的春 / 秋考期考 SC（或 NW/DB）。
4. 拿齐 2 张 → 合格证明书复印件 + 日译，在下次在留 / 永住申请时计入 +10。
5. 别忘了这只是 +10；结合你已有的 70→90 分总览（`japan_hsp_points_70_to_90_survey_20260527.md`），日语 N1(+15) / 母校告示登载(+10) / 已授权专利(+15) 往往比 IT 资格更高杠杆——IT 资格的价值在于"确定性高、可自控"。
