## 1. 接続表現 / 条件・場合

### 1. ～にしろ / ～にせよ
- **意味**：即使……也，不管……都（让步）
- **接続**：[N / V-辞書/普通形 / イA / ナA(である)] + にしろ／にせよ
- **使用场景**：列举两个或多个对立项后总结。考试中常以「AにしろBにしろ」形式出现。
- **例文**：
  1. 賛成するにせよ反対するにせよ、理由を明確にすべきだ。 → 不论赞成还是反对，都应当说明理由。
  2. 学生にしろ社会人にしろ、時間管理は重要だ。 → 不管是学生还是社会人，时间管理都很重要。
- **辨析**：比「～ても」更书面；「～にしろ～にしろ」=「～にせよ～にせよ」完全同义。

### 2. ～にしても
- **意味**：即使……也；就算……也
- **接続**：[N / V-普通形 / イA / ナA] + にしても
- **使用场景**：表示让步并紧接说话人评价。
- **例文**：
  1. 忙しいにしても、連絡くらいはできるはずだ。 → 就算忙，至少也该联系一下吧。
  2. 冗談にしても、その発言は失礼だ。 → 就算是开玩笑，那种话也太失礼了。
- **辨析**：「～にしろ／にせよ」更正式；「～にしても」口语和书面都可以。

### 3. ～としても
- **意味**：即使……也（假设性让步）
- **接続**：[N / V-普通形 / イA / ナA(だ)] + としても
- **使用场景**：假设一种情况，表示即便如此结论仍然成立。
- **例文**：
  1. 雨が降ったとしても、試合は中止しない。 → 即使下雨，比赛也不会中止。
  2. 本当だとしても、信じられない話だ。 → 即使是真的，也是难以置信的事。
- **辨析**：与「～ても」近义，但「としても」更强调"假设"含义。

### 4. ～ば～ほど
- **意味**：越……越……
- **接続**：[V-ば形] + [V-辞書形] + ほど；イA-ければ + イA + ほど；ナA-であれば + ナA + であるほど
- **使用场景**：表示程度同步变化。
- **例文**：
  1. 考えれば考えるほど分からなくなる。 → 越想越糊涂。
  2. この本は読めば読むほど面白い。 → 这本书越读越有意思。
- **辨析**：N2 必考；注意名词形态用「Nであれば～Nであるほど」。

### 5. ～さえ～ば
- **意味**：只要……就……
- **接続**：[N] + さえ + [V-ば形 / イA-ければ / ナA-であれば]；[V-ます形] + さえすれば
- **使用场景**：强调最低条件即可满足。
- **例文**：
  1. お金さえあれば何でもできるわけではない。 → 并非只要有钱什么都能做。
  2. 練習しさえすれば上達する。 → 只要练习就会进步。
- **辨析**：「～さえ」单独表"连……都"（极端例），「～さえ～ば」是固定条件句型。

### 6. ～ものなら
- **意味**：如果能……的话（多含难以实现之意）
- **接続**：[V-可能形辞書形] + ものなら
- **使用场景**：表达难以实现的愿望，后接「～たい」类。
- **例文**：
  1. 行けるものなら、明日にでも故郷に帰りたい。 → 要是能去，明天就想回故乡。
  2. やめられるものならやめたいが、仕事だから仕方ない。 → 要是能辞我也想辞，但这是工作没办法。
- **辨析**：与「～(よ)うものなら」（一旦……就糟）形式相近但意义不同，注意区分（见下条）。

### 7. ～(よ)うものなら
- **意味**：万一……的话（就糟糕了）
- **接続**：[V-意向形] + ものなら
- **使用场景**：表达一旦发生某事就会带来严重后果。
- **例文**：
  1. 父に知られようものなら、大変なことになる。 → 一旦被父亲知道就完蛋了。
  2. 一言でも反対しようものなら、彼は怒り出すだろう。 → 哪怕只反对一句他就会发火。
- **辨析**：与「～ものなら」（可能形）区分关键在动词形态——意向形=糟糕假设。

### 8. ～たら最後 / ～たが最後
- **意味**：一旦……就（无可挽回）
- **接続**：[V-た形] + ら最後／が最後
- **使用场景**：强调一旦发生就会有不可逆的负面结果。
- **例文**：
  1. 彼に貸したら最後、二度と返ってこない。 → 一旦借给他就再也回不来了。
  2. 怒り出したが最後、誰の言うことも聞かない。 → 他一发火就谁的话都不听。
- **辨析**：比「～たら」语气强烈得多，必带负面结果。

### 9. ～次第 (Vます形 + 次第)
- **意味**：一……就立刻……
- **接続**：[V-ます形] + 次第
- **使用场景**：商务/正式场合表"一旦完成就立即"。
- **例文**：
  1. 詳細が分かり次第、ご連絡いたします。 → 一了解详情我就联系您。
  2. 到着し次第、出発します。 → 一到达就立刻出发。
- **辨析**：「次第」另有「N次第だ」=取决于N；「～次第で」=根据……（见后条）。

### 10. ～につけ / ～につけて
- **意味**：每当……就……
- **接続**：[V-辞書形 / N] + につけ(て)
- **使用场景**：表伴随感情自然涌出。常以「何かにつけ」「何につけ」固定。
- **例文**：
  1. この写真を見るにつけ、母を思い出す。 → 每当看到这张照片就想起母亲。
  2. 何かにつけ彼は私を批判する。 → 动不动他就批评我。
- **辨析**：与「～たびに」近义，但「につけ」更强调情感反应。

### 11. ～にあたって / ～にあたり
- **意味**：在……之际，值……之时
- **接続**：[V-辞書形 / N] + にあたって／にあたり
- **使用场景**：正式场合表行为开始之际。
- **例文**：
  1. 開会にあたり、一言ご挨拶申し上げます。 → 在开幕之际，请允许我说几句。
  2. 新生活を始めるにあたって、目標を立てた。 → 在开始新生活之际定下了目标。
- **辨析**：与「～にさいして」近义，但「にあたって」更强调"正面对的关键时刻"。

### 12. ～にさいして / ～にさいし
- **意味**：在……之际
- **接続**：[V-辞書形 / N] + にさいして
- **使用场景**：正式书面，多用于仪式、声明。
- **例文**：
  1. 入学にさいして、保護者の同意が必要だ。 → 入学之际需要监护人同意。
  2. 出発にさいし、注意事項を確認した。 → 出发之际确认了注意事项。
- **辨析**：「にあたって」更口语化一点；「にさいして」最正式。

### 13. ～にあって
- **意味**：处于……（情形/时代/立场）
- **接続**：[N] + にあって
- **使用场景**：书面用语，描述特殊环境或处境。
- **例文**：
  1. 現代社会にあって、情報リテラシーは不可欠だ。 → 处于现代社会，信息素养不可或缺。
  2. 非常時にあって、冷静さが求められる。 → 在非常时期，需要冷静。
- **辨析**：与「において」近义，「にあって」更强调"身处其中"。

### 14. ～において / ～における
- **意味**：在……（场所・时间・领域）
- **接続**：[N] + において／における + N
- **使用场景**：书面/正式，「で」的文语版。
- **例文**：
  1. 会議は本日午後、本社において行われる。 → 会议今日下午在总部举行。
  2. 教育における平等は重要な課題だ。 → 教育领域的平等是重要课题。
- **辨析**：「において」=「で」；「における」=「での」（连体修饰用）。

## 2. 原因・理由

### 15. ～ばかりに
- **意味**：就因为……（导致不好结果）
- **接続**：[V-た形 / イA / ナA-な / N-である] + ばかりに
- **使用场景**：消极结果的原因，含懊悔语气。
- **例文**：
  1. 寝坊したばかりに、試験に遅刻した。 → 就因为睡过头，考试迟到了。
  2. 一言多かったばかりに、彼を怒らせてしまった。 → 就因为多说了一句话，惹他生气了。
- **辨析**：必接负面结果；与「～だけに」（正反皆可，含"果然"）不同。

### 16. ～だけに
- **意味**：正因为……所以……（果然/更加）
- **接続**：[V-普通形 / イA / ナA-な / N-である] + だけに
- **使用场景**：强调原因与结果的相称性，常含"果然如此"感。
- **例文**：
  1. ベテランの選手だけに、プレッシャーに強い。 → 不愧是老选手，抗压能力强。
  2. 期待していただけに、結果に失望した。 → 正因为有所期待，对结果更失望。
- **辨析**：可正可负；「ばかりに」只接负面。

### 17. ～だけあって
- **意味**：不愧是……，正因为是……所以……
- **接続**：[V-普通形 / イA / ナA-な / N] + だけあって
- **使用场景**：表正面评价，强调名副其实。
- **例文**：
  1. 留学経験があるだけあって、英語が流暢だ。 → 不愧有留学经验，英语流利。
  2. 高いだけあって、品質がいい。 → 贵自有贵的道理，质量好。
- **辨析**：与「だけに」近，但「だけあって」更纯正面。

### 18. ～あまり / ～あまりに
- **意味**：因为太过……
- **接続**：[V-辞書/た形 / イA-さ / ナA-な / N-の] + あまり
- **使用场景**：表过度状态导致的结果。
- **例文**：
  1. 緊張のあまり、声が震えた。 → 紧张过度声音都颤抖了。
  2. 喜びのあまり、涙が出た。 → 高兴得流泪了。
- **辨析**：「あまり」前多接情绪/感情类名词。

### 19. ～あげく / ～あげくに
- **意味**：……结果（最后）……（多负面）
- **接続**：[V-た形 / N-の] + あげく
- **使用场景**：经过长时间反复后得出的负面结局。
- **例文**：
  1. 散々悩んだあげく、留学を諦めた。 → 苦恼了半天，最后放弃了留学。
  2. 議論のあげく、結論は出なかった。 → 讨论的结果是没有得出结论。
- **辨析**：与「～末に」近似，但「あげく」多负面，「末に」中性偏正面。

### 20. ～末に / ～末
- **意味**：……的结果（经历后终于）
- **接続**：[V-た形 / N-の] + 末(に)
- **使用场景**：经过努力或长过程后得出的结论，中性/正面居多。
- **例文**：
  1. 長時間の話し合いの末、合意に達した。 → 经过长时间讨论终于达成共识。
  2. 悩んだ末に、転職を決意した。 → 苦恼很久后下决心跳槽。
- **辨析**：与「あげく」对比记忆：「末に」=正面/中性，「あげく」=负面。

### 21. ～せいで / ～せいか / ～せいだ
- **意味**：因为……（多归咎）；～せいか=可能是因为
- **接続**：[V-普通形 / イA / ナA-な / N-の] + せいで／せいか／せいだ
- **使用场景**：归因，常含责备语气。
- **例文**：
  1. 雨のせいで、試合が中止になった。 → 因为下雨，比赛取消了。
  2. 寝不足のせいか、頭が痛い。 → 可能是因为没睡好，头疼。
- **辨析**：「おかげで」=正面；「せいで」=负面；「せいか」=不确定推测。

### 22. ～おかげで / ～おかげか
- **意味**：多亏……，托……的福
- **接続**：[V-た形 / イA / ナA-な / N-の] + おかげで
- **使用场景**：表感谢或正面归因。
- **例文**：
  1. 先生のおかげで合格できた。 → 多亏老师才合格。
  2. 天気がよかったおかげで、楽しい旅行になった。 → 多亏天气好，旅行很愉快。
- **辨析**：偶有反讽用法「お前のおかげで」=都怪你。

### 23. ～ことから
- **意味**：因为……（客观陈述原因）
- **接続**：[V-普通形 / イA / ナA-な・である / N-である] + ことから
- **使用场景**：客观说明根据，常用于报道/解释来源。
- **例文**：
  1. 桜が多く植えられていることから、この公園は有名になった。 → 因为种了很多樱花，这个公园出名了。
  2. 古くから貿易港であったことから、外国文化が早く入ってきた。 → 因为自古以来是贸易港，外国文化很早就传入了。
- **辨析**：常用于解释命名/起源/由来。

### 24. ～ことだから
- **意味**：因为是……（基于对某人的了解推测）
- **接続**：[N-の] + ことだから
- **使用场景**：以"我了解他/她"为前提进行的推测。
- **例文**：
  1. 真面目な彼のことだから、きっと時間通りに来るだろう。 → 以他认真的性格，肯定会准时来。
  2. 子どものことだから、許してあげよう。 → 毕竟是孩子，原谅他吧。
- **辨析**：必接 N の，前面通常是人名/称呼，含"基于其性格"推测之意。

## 3. 逆接・譲歩

### 25. ～ものの
- **意味**：虽然……但是……
- **接続**：[V-普通形 / イA / ナA-な・である / N-である] + ものの
- **使用场景**：书面语，前后矛盾或预期不符。
- **例文**：
  1. 大学は卒業したものの、就職先が決まらない。 → 虽然大学毕业了，但工作还没着落。
  2. 約束はしたものの、行きたくない。 → 虽然答应了，但不想去。
- **辨析**：与「けれども」近，但「ものの」更书面、含"实际状态与预期不符"感。

### 26. ～とはいうものの
- **意味**：话虽如此，但……
- **接続**：[文] + とはいうものの
- **使用场景**：承认前述但提出反例。
- **例文**：
  1. 春とはいうものの、まだ寒い日が続く。 → 虽说是春天，但还是接连寒冷。
  2. 安いとはいうものの、品質が悪ければ買わない。 → 话虽便宜，但质量差也不会买。

### 27. ～にもかかわらず
- **意味**：尽管……还是……
- **接続**：[V-普通形 / イA / ナA(である) / N(である)] + にもかかわらず
- **使用场景**：书面，强烈的逆接。
- **例文**：
  1. 雨にもかかわらず、試合は予定通り行われた。 → 尽管下雨，比赛仍按计划进行。
  2. 努力したにもかかわらず、失敗した。 → 尽管努力了还是失败了。
- **辨析**：比「のに」更正式；侧重"事实与预想反差大"。

### 28. ～くせに
- **意味**：明明……却……（含贬义/不满）
- **接続**：[V-普通形 / イA / ナA-な / N-の] + くせに
- **使用场景**：批评、指责他人言行不一致。
- **例文**：
  1. 知らないくせに、知ったかぶりをする。 → 明明不知道，却装懂。
  2. 子どものくせに、生意気だ。 → 明明是孩子，却很狂。
- **辨析**：与「のに」近，但「くせに」必带负面情绪，且多用于指责他人。

### 29. ～ながら(も)
- **意味**：虽然……却……
- **接続**：[V-ます形 / イA / ナA / N] + ながら(も)
- **使用场景**：书面，前后矛盾的状态。
- **例文**：
  1. 狭いながらも、楽しい我が家。 → 虽然狭小但快乐的家。
  2. 残念ながら、結果は不合格でした。 → 很遗憾，结果是不合格。
- **辨析**：与表"一边……一边……"的「ながら」同形不同义，靠上下文判断。

### 30. ～つつ(も)
- **意味**：虽然……却……（书面）
- **接続**：[V-ます形] + つつ(も)
- **使用场景**：表与本意相反的行为或矛盾心理。
- **例文**：
  1. 悪いと知りつつも、嘘をついてしまった。 → 明知不对还是撒了谎。
  2. 体に悪いと思いつつ、タバコをやめられない。 → 明知对身体不好却戒不掉烟。
- **辨析**：「つつ」（不带も）=一边……一边……；「つつも」=逆接。

### 31. ～といっても
- **意味**：虽说……但其实……
- **接続**：[V/イA/ナA/N の普通形] + といっても
- **使用场景**：纠正听者的过高/过低想象。
- **例文**：
  1. 日本に住んでいたといっても、たった三ヶ月だ。 → 虽说在日本住过，也就三个月。
  2. 社長といっても、社員は三人だけだ。 → 虽说是社长，员工就三个人。

### 32. ～といえども
- **意味**：即使是……也……
- **接続**：[N / V-普通形] + といえども
- **使用场景**：书面/正式，极端让步。
- **例文**：
  1. 子供といえども、責任は免れない。 → 即使是孩子也免不了责任。
  2. プロといえども、失敗することはある。 → 即使是专业人士也会失败。
- **辨析**：比「であっても」更书面，多用于格言/评论文。

### 33. ～とはいえ
- **意味**：虽说……但……
- **接続**：[V/イA/ナA/N の普通形] + とはいえ
- **使用场景**：书面，承认前述但提出反差。
- **例文**：
  1. 暦の上では春とはいえ、寒さは厳しい。 → 虽说历法上是春天，寒意仍然刺骨。
  2. 子どもとはいえ、悪事は許せない。 → 虽说是孩子，坏事也不能纵容。

### 34. ～ものを
- **意味**：……就好了（带遗憾/责备）
- **接続**：[V-普通形 / イA / ナA-な] + ものを
- **使用场景**：表对方未采取应有行动的遗憾或责备。
- **例文**：
  1. 早く言ってくれればよかったものを。 → 早点告诉我就好了……
  2. 黙っていればいいものを、余計なことを言った。 → 沉默就好了，偏要多嘴。

### 35. ～ところを
- **意味**：在……的时候（打扰、感谢）
- **接続**：[V-ている / イA / ナA-な / N-の] + ところを
- **使用场景**：礼貌寒暄打断对方。
- **例文**：
  1. お忙しいところをすみません。 → 在您忙的时候打扰了。
  2. 寝ているところを起こされた。 → 睡得正香被叫醒了。

### 36. ～にしては
- **意味**：作为……来说（评价与预期不符）
- **接続**：[N / V-普通形] + にしては
- **使用场景**：基于身份/状况的评价。
- **例文**：
  1. 子どもにしては、しっかりしている。 → 作为孩子来说很懂事。
  2. 初めて作ったにしては、上手だ。 → 作为第一次做来说做得不错。
- **辨析**：与「わりに」近，但「にしては」前需明确基准。

### 37. ～わりに(は)
- **意味**：相比……来说……
- **接続**：[V-普通形 / イA / ナA-な / N-の] + わりに(は)
- **使用场景**：与一般预期对比时使用。
- **例文**：
  1. 値段のわりに、品質がいい。 → 相对于价格来说，质量很好。
  2. よく勉強しているわりには、成績が伸びない。 → 学得不少但成绩不见涨。

### 38. ～ばこそ
- **意味**：正因为……才……
- **接続**：[V-ば形 / イA-ければ / ナA-であれば / N-であれば] + こそ
- **使用场景**：书面，强烈强调原因。
- **例文**：
  1. 健康であればこそ、仕事も楽しめる。 → 正因为健康才能享受工作。
  2. 君を思えばこそ厳しいことを言うのだ。 → 正因为为你着想才说严厉的话。

## 4. 程度・限度・基準

### 39. ～限り(では)
- **意味**：就……的范围而言
- **接続**：[V-辞書/た形 / N-の] + 限り(では)
- **使用场景**：限定信息来源/认知范围。
- **例文**：
  1. 私の知る限り、彼は正直な人だ。 → 据我所知他是个诚实的人。
  2. 調べた限りでは、問題はない。 → 就查到的来说没问题。

### 40. ～限り (= 只要)
- **意味**：只要……（在……的状态持续期间）
- **接続**：[V-辞書/ている形 / イA / ナA-である / N-である] + 限り
- **使用场景**：表持续条件。
- **例文**：
  1. 体が元気な限り、働き続けたい。 → 只要身体健康就想继续工作。
  2. 練習を続ける限り、上達するはずだ。 → 只要继续练习就会进步。

### 41. ～ない限り
- **意味**：除非……否则不……
- **接続**：[V-ない形 / イA-くない / ナA-でない / N-でない] + 限り
- **使用场景**：必要条件的否定式表达。
- **例文**：
  1. 努力しない限り、成功はない。 → 不努力就没有成功。
  2. 雨が降らない限り、試合は行われる。 → 除非下雨，否则比赛进行。

### 42. ～に限り / ～に限って
- **意味**：仅限……；偏偏……（に限って）
- **接続**：[N] + に限り／に限って
- **使用场景**：「に限り」=正式公告，「に限って」=偶然/意外的不巧。
- **例文**：
  1. 本日に限り、半額セール。 → 仅今日半价促销。
  2. 急いでいる時に限って、電車が遅れる。 → 偏偏赶时间的时候电车晚点。

### 43. ～に限らず
- **意味**：不仅限于……
- **接続**：[N] + に限らず
- **使用场景**：扩大范围。
- **例文**：
  1. 日本に限らず、世界中で問題になっている。 → 不仅日本，全世界都成了问题。
  2. 男性に限らず女性も応募できる。 → 不仅男性女性也可以报名。

### 44. ～ほど (程度)
- **意味**：到……的程度
- **接続**：[V-辞書形 / イA / ナA-な / N] + ほど
- **使用场景**：表事物程度。
- **例文**：
  1. 死ぬほど疲れた。 → 累得要死。
  2. 思っていたほど難しくなかった。 → 没有想象的那么难。

### 45. ～ほどのことではない
- **意味**：不至于……，没到那地步
- **接続**：[V-辞書形] + ほどのことではない
- **使用场景**：弱化事态严重性。
- **例文**：
  1. 病院に行くほどのことではない。 → 没严重到要去医院。
  2. 騒ぐほどのことではない。 → 没必要大惊小怪。

### 46. ～くらい / ～ぐらい
- **意味**：……的程度；至少……（最低限）
- **接続**：[V-辞書/た形 / イA / ナA-な / N] + くらい
- **使用场景**：示例程度，或表"起码"。
- **例文**：
  1. 立てないくらい疲れた。 → 累得站不起来。
  2. 挨拶くらいしなさい。 → 至少打个招呼。

### 47. ～にすぎない
- **意味**：只不过是……
- **接続**：[V-普通形 / N] + にすぎない
- **使用场景**：贬低/降低评价。
- **例文**：
  1. ただの噂にすぎない。 → 只不过是谣言而已。
  2. 私は手伝ったにすぎない。 → 我只不过帮了忙而已。

### 48. ～どころではない
- **意味**：哪里谈得上……（无暇/不是那种程度）
- **接続**：[V-辞書形 / N] + どころではない
- **使用场景**：否定当前状态足以做某事。
- **例文**：
  1. 忙しくて、旅行どころではない。 → 忙得哪有空旅行。
  2. 仕事が山積みで休むどころではない。 → 工作堆成山，哪谈得上休息。

### 49. ～までもない
- **意味**：用不着……，没必要……
- **接続**：[V-辞書形] + までもない
- **使用场景**：表事情显而易见/不必特意做。
- **例文**：
  1. 言うまでもなく、健康が一番だ。 → 不用说，健康最重要。
  2. わざわざ説明するまでもない。 → 用不着特地解释。

### 50. ～までだ / ～までのことだ
- **意味**：大不了就……，仅此而已
- **接続**：[V-辞書/た形] + までだ／までのことだ
- **使用场景**：表心理预设的最终手段。
- **例文**：
  1. 断られたら、諦めるまでだ。 → 被拒绝大不了就放弃。
  2. やるだけのことはやった。あとは結果を待つまでだ。 → 该做的都做了，剩下的就只等结果。

### 51. ～に応じて / ～に応じた
- **意味**：根据……，与……相应
- **接続**：[N] + に応じて／に応じた + N
- **使用场景**：表根据情况调整。
- **例文**：
  1. 収入に応じて税金を払う。 → 根据收入纳税。
  2. 客のニーズに応じた商品を提供する。 → 提供与客户需求相应的商品。

### 52. ～次第で / ～次第だ
- **意味**：取决于……，根据……
- **接続**：[N] + 次第で／次第だ
- **使用场景**：表结果由某条件决定。
- **例文**：
  1. 努力次第で結果は変わる。 → 结果取决于努力。
  2. 成功するかどうかは君次第だ。 → 能否成功取决于你。
- **辨析**：与「V-ます形+次第」（一……就……）区分，前者接 N。

## 5. 並列・添加・累加

### 53. ～上に
- **意味**：而且……，加之……
- **接続**：[V-普通形 / イA / ナA-な・である / N-の・である] + 上に
- **使用场景**：前后同方向累加。
- **例文**：
  1. この店は安い上に美味しい。 → 这家店便宜而且好吃。
  2. 雨が降った上に、風も強くなった。 → 下了雨而且风也大了。
- **辨析**：累加项语气方向必须一致（同正同负）。

### 54. ～に加えて
- **意味**：再加上……
- **接続**：[N] + に加えて
- **使用场景**：书面，追加要素。
- **例文**：
  1. 風に加えて雨も降り出した。 → 风之外又开始下雨了。
  2. 経験に加えて知識も必要だ。 → 除了经验还需要知识。

### 55. ～のみならず
- **意味**：不仅……而且……
- **接続**：[V-普通形 / イA / ナA-である / N(である)] + のみならず
- **使用场景**：书面，扩大范围。
- **例文**：
  1. 彼は英語のみならず中国語も話せる。 → 他不仅会英语还会汉语。
  2. 学生のみならず社会人にも人気がある。 → 不仅学生连社会人也喜欢。

### 56. ～ばかりか / ～ばかりでなく
- **意味**：不仅……而且……
- **接続**：[V-普通形 / イA / ナA-な / N] + ばかりか／ばかりでなく
- **使用场景**：口语+书面通用。
- **例文**：
  1. 雨ばかりか雪まで降り出した。 → 不仅下雨甚至下起雪了。
  2. 彼は頭がいいばかりでなく、性格もいい。 → 他不仅聪明性格也好。

### 57. ～はもとより / ～はもちろん
- **意味**：……不用说，……也……
- **接続**：[N] + はもとより／はもちろん
- **使用场景**：「もとより」更书面。
- **例文**：
  1. 子供はもとより、大人も楽しめる。 → 不用说孩子，大人也能享受。
  2. 平日はもちろん、週末も営業している。 → 平日不用说，周末也营业。

### 58. ～にしても～にしても
- **意味**：无论……还是……都……
- **接続**：[N / V-普通形] + にしても + 同 + にしても
- **使用场景**：并列两选项后总结。
- **例文**：
  1. 行くにしても行かないにしても、早く決めて。 → 去也好不去也好，快决定。
  2. 賛成にしても反対にしても、意見を聞かせて。 → 赞成也好反对也好，说说你的意见。

### 59. ～やら～やら
- **意味**：又……又……（多事/多物并列）
- **接続**：[V-辞書形 / イA / N] + やら + 同 + やら
- **使用场景**：列举多个事物，常含繁杂感。
- **例文**：
  1. 嬉しいやら恥ずかしいやら、複雑な気持ちだ。 → 又开心又不好意思，心情复杂。
  2. 仕事やら子育てやらで忙しい。 → 工作呀育儿呀忙得很。

### 60. ～だの～だの
- **意味**：又……又……（列举抱怨）
- **接続**：[V-普通形 / イA / N] + だの + 同 + だの
- **使用场景**：含不满，对所列内容贬抑。
- **例文**：
  1. 高いだの遠いだのと文句ばかり。 → 又嫌贵又嫌远净抱怨。
  2. 肉だの魚だのとうるさい。 → 又肉又鱼挑三拣四。

### 61. ～と言わず～と言わず
- **意味**：不分……不分……，都……
- **接続**：[N] + と言わず + N + と言わず
- **使用场景**：强调无差别全部。
- **例文**：
  1. 顔と言わず手と言わず、傷だらけだ。 → 脸啊手啊都是伤。
  2. 昼と言わず夜と言わず働き続けた。 → 不分白天黑夜地工作。

### 62. ～も～ば～も
- **意味**：又有……又有……
- **接続**：[N も] + [V-ば形 / イA-ければ / ナA-であれば] + N も
- **使用场景**：并列两种情况。
- **例文**：
  1. 雨も降れば風も吹く。 → 又下雨又刮风。
  2. 勉強もすればスポーツもする。 → 既学习又运动。

### 63. ～かたわら
- **意味**：一方面……一方面（另有副业/活动）
- **接続**：[V-辞書形 / N-の] + かたわら
- **使用场景**：书面，主业之外兼做某事。
- **例文**：
  1. 大学で教えるかたわら、執筆活動も行っている。 → 在大学任教的同时也从事写作。
  2. 仕事のかたわら、ボランティアをしている。 → 工作之余做志愿者。

### 64. ～と同時に
- **意味**：与……同时
- **接続**：[V-辞書形 / N(である) / イA / ナA(である)] + と同時に
- **使用场景**：表两件事同时发生或并存。
- **例文**：
  1. 卒業すると同時に就職した。 → 毕业的同时就职了。
  2. 彼は教師であると同時に作家でもある。 → 他既是教师又是作家。

## 6. 時間関係

### 65. ～うちに
- **意味**：趁……的时候；不知不觉……
- **接続**：[V-辞書/ない/ている形 / イA / ナA-な / N-の] + うちに
- **使用场景**：「ない形+うちに」=趁还没……；「ている+うちに」=在……过程中不知不觉。
- **例文**：
  1. 暗くならないうちに帰ろう。 → 趁天没黑回去吧。
  2. 話しているうちに眠くなった。 → 说着说着就困了。

### 66. ～最中に / ～最中だ
- **意味**：正在……的时候
- **接続**：[V-ている / N-の] + 最中(に)
- **使用场景**：强调"动作正进行中被打断"。
- **例文**：
  1. 食事の最中に電話がかかってきた。 → 正吃饭时来了电话。
  2. 会議の最中に居眠りしてしまった。 → 开会的当口睡着了。

### 67. ～かと思うと / ～かと思ったら
- **意味**：刚……就……
- **接続**：[V-た形] + かと思うと／かと思ったら
- **使用场景**：表意外的连续动作。
- **例文**：
  1. 帰ってきたかと思うと、また出かけた。 → 刚回来又出去了。
  2. 泣いたかと思ったら、もう笑っている。 → 刚哭完又笑了。

### 68. ～か～ないかのうちに
- **意味**：刚一……就……
- **接続**：[V-辞書/た形] + か + [V-ない形] + かのうちに
- **使用场景**：极短时间连续。
- **例文**：
  1. ベルが鳴るか鳴らないかのうちに、教室を飛び出した。 → 铃声刚响就冲出教室。
  2. 横になるかならないかのうちに眠ってしまった。 → 刚躺下就睡着了。

### 69. ～が早いか
- **意味**：刚一……就立刻……
- **接続**：[V-辞書/た形] + が早いか
- **使用场景**：书面，强调动作连贯。
- **例文**：
  1. 席に着くが早いか、食べ始めた。 → 一坐下就开始吃。
  2. ベルが鳴るが早いか、走り出した。 → 铃声一响就跑出去了。

### 70. ～や / ～や否や
- **意味**：一……就……
- **接続**：[V-辞書形] + や(否や)
- **使用场景**：书面/文学，强调瞬间连接。
- **例文**：
  1. ドアを開けるや、犬が飛び出してきた。 → 一开门狗就冲出来。
  2. 知らせを聞くや否や、駆けつけた。 → 一听到消息就赶过去。

### 71. ～たとたん(に)
- **意味**：刚一……就……（意外发生）
- **接続**：[V-た形] + とたん(に)
- **使用场景**：强调意外的瞬间结果。
- **例文**：
  1. 立ち上がったとたん、めまいがした。 → 一站起来就头晕。
  2. ドアを開けたとたん、猫が飛び出した。 → 一开门猫就窜出来了。

### 72. ～際(に) / ～際は
- **意味**：……之时（正式）
- **接続**：[V-辞書/た形 / N-の] + 際(に)
- **使用场景**：书面/商务。
- **例文**：
  1. お帰りの際は気をつけて。 → 回去时请小心。
  2. ご来店の際にはご持参ください。 → 光临时请带上。

### 73. ～折に / ～折には
- **意味**：……之际（书面，正式信函常用）
- **接続**：[V-辞書/た形 / N-の] + 折(に)
- **使用场景**：书信寒暄。
- **例文**：
  1. 上京の折にはぜひお立ち寄りください。 → 来东京时请一定光临。
  2. お会いした折にお話しします。 → 见面时再说。

### 74. ～てからというもの
- **意味**：自从……以来（变化持续）
- **接続**：[V-て形] + からというもの
- **使用场景**：强调某事件后状态长期改变。
- **例文**：
  1. 彼に出会ってからというもの、毎日が楽しい。 → 自从遇见他每天都很开心。
  2. 引っ越してからというもの、通勤が大変になった。 → 自从搬家通勤变累了。

### 75. ～て以来
- **意味**：自从……以来
- **接続**：[V-て形] + 以来
- **使用场景**：客观陈述时间起点。
- **例文**：
  1. 卒業して以来、彼に会っていない。 → 毕业以来没见过他。
  2. 来日して以来、ずっとアルバイトしている。 → 来日本以来一直在打工。

### 76. ～矢先に
- **意味**：正要……的时候
- **接続**：[V-辞書/た形・ようとする] + 矢先(に)
- **使用场景**：动作将要开始的瞬间。
- **例文**：
  1. 出かけようとした矢先に電話が鳴った。 → 正要出门电话就响了。
  2. 寝ようとした矢先、地震が起きた。 → 正要睡时发生了地震。

### 77. ～にわたって / ～にわたる
- **意味**：历经……，遍及……
- **接続**：[N（時間/範囲）] + にわたって／にわたる+N
- **使用场景**：表广泛/长时间的范围。
- **例文**：
  1. 三日間にわたって会議が行われた。 → 历时三天召开了会议。
  2. 全国にわたる調査が実施された。 → 进行了遍及全国的调查。

### 78. ～を通じて / ～を通して
- **意味**：通过……；自始至终
- **接続**：[N] + を通じて／を通して
- **使用场景**：表媒介或持续期间。
- **例文**：
  1. 友人を通じて知り合った。 → 通过朋友认识的。
  2. 一年を通じて温暖だ。 → 一年到头都温暖。

## 7. 推量・判断

### 79. ～にちがいない
- **意味**：一定……（强推测）
- **接続**：[V-普通形 / イA / ナA / N] + にちがいない
- **使用场景**：高确信度的判断。
- **例文**：
  1. 彼は犯人にちがいない。 → 他一定是犯人。
  2. 雨が降っているにちがいない。 → 一定在下雨。

### 80. ～にきまっている
- **意味**：肯定……（口语，主观断定）
- **接続**：[V-普通形 / イA / ナA / N] + にきまっている
- **使用场景**：口语强烈断言。
- **例文**：
  1. そんな話、嘘にきまっている。 → 那种话肯定是假的。
  2. こんな天気では遅れるにきまっている。 → 这种天气肯定会迟到。
- **辨析**：「にちがいない」=有根据；「にきまっている」=主观断言。

### 81. ～ものと思われる
- **意味**：被认为……（书面客观推定）
- **接続**：[V-普通形 / イA / ナA-である / N-である] + ものと思われる
- **使用场景**：新闻/报告书面用。
- **例文**：
  1. 原因は配線の不具合だったものと思われる。 → 原因被认为是线路故障。
  2. 影響は長期にわたるものと思われる。 → 预计影响将持续较长时间。

### 82. ～と見られる
- **意味**：被看作……
- **接続**：[V-普通形 / N(だ)] + と見られる
- **使用场景**：新闻报道客观推测。
- **例文**：
  1. 事件は計画的なものと見られる。 → 事件被认为是有预谋的。
  2. 関与した可能性が高いと見られている。 → 被认为参与的可能性较高。

### 83. ～恐れがある
- **意味**：有……的危险/可能（负面）
- **接続**：[V-辞書形 / N-の] + 恐れがある
- **使用场景**：天气预报/警告。
- **例文**：
  1. 大雨の恐れがある。 → 有下大雨的危险。
  2. 健康を害する恐れがある。 → 有损害健康的风险。

### 84. ～かねない
- **意味**：可能会……（负面）
- **接続**：[V-ます形] + かねない
- **使用场景**：表担忧的负面可能。
- **例文**：
  1. 過労で倒れかねない。 → 可能会因过劳倒下。
  2. このままでは失敗しかねない。 → 这样下去可能会失败。

### 85. ～かねる
- **意味**：难以……，无法……
- **接続**：[V-ます形] + かねる
- **使用场景**：礼貌拒绝/无法做到。
- **例文**：
  1. お答えしかねます。 → 难以回答（恕难奉告）。
  2. 賛成しかねる意見だ。 → 难以赞同的意见。

### 86. ～がたい
- **意味**：难以……
- **接続**：[V-ます形] + がたい
- **使用场景**：书面，表心理或道理上难以做到。
- **例文**：
  1. 信じがたい話だ。 → 难以置信的话。
  2. 忘れがたい思い出。 → 难以忘怀的回忆。

### 87. ～まい / ～まいか
- **意味**：不会……吧（否定推测）；不打算……（否定意志）
- **接続**：[V-辞書形] + まい；[V-ます形] + まい
- **使用场景**：书面，否定推测或意志。
- **例文**：
  1. もう二度と会うまい。 → 再也不见了（意志）。
  2. 彼は来るまい。 → 他大概不会来吧（推测）。

### 88. ～ようがない / ～ようもない
- **意味**：无法……，没办法……
- **接続**：[V-ます形] + ようがない
- **使用场景**：表客观上无法做到。
- **例文**：

  2. 言いようがないほど美しい。 → 美得无法形容。

## 8. 主張・断定・強調

### 92. ～にすぎない

### 93. ～に違いない（参见 #79）

### 95. ～こそ

### 98. ～以外の何ものでもない

  2. 彼の行動は犯罪以外の何ものでもない。 → 他的行为不折不扣就是犯罪。

  1. 時の流れは早いものだ。 → 时光过得真快啊。
  2. 子どもの頃はよく泣いたものだ。 → 小时候经常哭啊。

### 135. ～ものではない
- **意味**：不该……
- **接続**：[V-辞書形] + ものではない
- **使用场景**：教训/规劝。
- **例文**：
  1. 人を悪く言うものではない。 → 不该说人坏话。
  2. 嘘をつくものではない。 → 不该撒谎。

### 136. ～にすぎない（参见 #47）
- 仅仅是。

### 137. ～までだ（参见 #50）
- 大不了。

### 138. ～甲斐がある / ～甲斐がない
- **意味**：值得……／不值得……
- **接続**：[V-た形 / N-の] + 甲斐がある
- **使用场景**：行为是否值得回报。
- **例文**：
  1. 努力した甲斐があって合格した。 → 努力没白费考上了。
  2. 練習の甲斐もなく負けた。 → 白练了，输了。

### 139. ～にこしたことはない
- **意味**：……再好不过
- **接続**：[V-辞書形 / イA / ナA-である / N-である] + にこしたことはない
- **使用场景**：建议某事最好为之。
- **例文**：
  1. 早く始めるにこしたことはない。 → 早开始最好。
  2. 健康にこしたことはない。 → 没什么比健康更好。

### 140. ～ことに / ～ことには
- **意味**：令人……的是
- **接続**：[V-た形 / イA / ナA-な] + ことに
- **使用场景**：句首表强烈情感。
- **例文**：
  1. 驚いたことに、彼が一位だった。 → 令人吃惊的是他得了第一。
  2. 残念なことに、雨で中止だった。 → 遗憾的是因雨取消了。

## 13. 文末表現

### 141. ～次第だ（参见 #52）
- 取决于。

### 142. ～しまつだ
- **意味**：（最后）落到……的地步（负面）
- **接続**：[V-辞書形 / この/その + N-の] + しまつだ
- **使用场景**：经过不好的过程到达更不好的结果。

### 143. ～きらいがある
- **意味**：有……的倾向（负面）

- **使用场景**：书面，表不好的倾向。
- **例文**：
  1. 彼は物事を悲観的に考えるきらいがある。 → 他有悲观看问题的倾向。

### 146. ～ほどだ / ～くらいだ
- **意味**：……到了……的程度
- **接続**：[V-普通形 / イA / ナA-な] + ほどだ／くらいだ
- **使用场景**：举例说明程度。
- **例文**：
  1. 痛くて泣きたいくらいだ。 → 疼得想哭。
  2. 信じられないほどだ。 → 到了难以置信的程度。

### 147. ～ということだ / ～とのことだ
- **意味**：据说……，听说……
- **接続**：[文] + ということだ／とのことだ
- **使用场景**：传闻。
- **例文**：
  1. 来週から値上げするとのことだ。 → 据说下周开始涨价。
  2. 田中さんは退職したということだ。 → 听说田中辞职了。

### 148. ～わけだ
- **意味**：原来如此，难怪……
- **接続**：[V-普通形 / イA / ナA-な / N-である] + わけだ
- **使用场景**：表推论得出的合理解释。
- **例文**：
  1. 留学していたのか。どうりで英語が上手なわけだ。 → 留过学啊，难怪英语好。
  2. 寒いわけだ、外は雪だ。 → 难怪冷，外面下雪了。

### 149. ～ものだ (~であるものだ：本性)
- **意味**：本来就……（道理性断言）
- **接続**：[V-辞書/ない形 / イA / ナA-な] + ものだ
- **使用场景**：表普遍真理或本性。
- **例文**：
  1. 子どもは泣くものだ。 → 孩子哪有不哭的。
  2. 親は子を愛するものだ。 → 父母都疼孩子。

### 150. ～べきだ / ～べきではない
- **意味**：应该……／不应该……
- **接続**：[V-辞書形] + べきだ（する → するべき／すべき）
- **使用场景**：道德/义务建议。
- **例文**：
  1. 約束は守るべきだ。 → 应该遵守约定。
  2. そんなことを言うべきではない。 → 不该说那种话。

### 151. ～ものがある
- **意味**：有……的感觉/方面
- **接続**：[V-辞書形 / イA / ナA-な] + ものがある
- **使用场景**：感叹某事物含有某种特质。
- **例文**：
  1. 彼の演技には素晴らしいものがある。 → 他的演技有出色之处。
  2. 心を打つものがある。 → 有打动人心之处。

### 152. ～かのごとし / ～ごとし
- **意味**：宛如……
- **接続**：[N-の / V-辞書形] + ごとし
- **使用场景**：古文味浓的比喻，文学。
- **例文**：
  1. 光陰矢のごとし。 → 光阴似箭。
  2. 流れるごとき動作。 → 行云流水般的动作。

## 14. 敬語・形式名詞表現

### 153. お／ご～する / お／ご～いたす
- **意味**：（自谦）我做……
- **接続**：お + V-ます形 + する／いたす；ご + 漢語動名詞 + する／いたす
- **使用场景**：商务客户应对。
- **例文**：
  1. お持ちいたします。 → 我来拿。
  2. ご案内します。 → 我来引导。

### 154. お／ご～になる
- **意味**：（尊他）您做……
- **接続**：お + V-ます形 + になる；ご + 漢語動名詞 + になる
- **使用场景**：尊敬对方的动作。
- **例文**：
  1. 先生がお話しになる。 → 老师讲话。
  2. ご利用になりますか。 → 您要使用吗？

### 155. ～させていただく
- **意味**：请允许我……
- **接続**：[V-使役て形] + いただく
- **使用场景**：商务最高谦让，征求许可。
- **例文**：
  1. 発表させていただきます。 → 请允许我做报告。
  2. お休みさせていただきます。 → 请允许我请假。

### 156. ～てくださる / ～ていただく
- **意味**：为我做……
- **接続**：[V-て形] + くださる／いただく
- **使用场景**：表受惠与谢意。
- **例文**：
  1. 教えてくださってありがとうございます。 → 感谢您教我。
  2. ご紹介いただきありがとうございます。 → 感谢您介绍。

### 157. ～申し上げる
- **意味**：（最郑重谦让）我向您……
- **接続**：お／ご + V-ます形／漢語動名詞 + 申し上げる
- **使用场景**：商务信函/正式致辞。
- **例文**：
  1. お願い申し上げます。 → 恳请您……
  2. ご報告申し上げます。 → 谨向您报告。

### 158. ～願う
- **意味**：请求……
- **接続**：お／ご + V-ます形／漢語動名詞 + 願う
- **使用场景**：正式请求/告示。
- **例文**：
  1. ご注意願います。 → 请您注意。
  2. ご協力願います。 → 请您协助。

### 159. ～かたがた
- **意味**：顺便……，兼……
- **接続**：[N] + かたがた
- **使用场景**：书面礼貌信函。
- **例文**：
  1. お礼かたがたご報告まで。 → 既表谢意亦作报告。
  2. ご挨拶かたがた伺いました。 → 顺便登门致意。

### 160. ～がてら
- **意味**：顺便……
- **接続**：[V-ます形 / N] + がてら
- **使用场景**：口语，做 A 顺便做 B。
- **例文**：
  1. 散歩がてら買い物に行く。 → 顺便散步去买东西。
  2. 帰りがてら寄ってくれた。 → 回去顺路来了。

## 15. 接続助詞・複合助詞

### 161. ～をめぐって / ～をめぐる
- **意味**：围绕……
- **接続**：[N] + をめぐって／をめぐる + N
- **使用场景**：议论的中心议题。
- **例文**：
  1. 環境問題をめぐって議論が続いている。 → 围绕环保问题持续讨论。
  2. 遺産をめぐる争いが起きた。 → 发生了围绕遗产的纷争。

### 162. ～をもとに(して) / ～をもとにした
- **意味**：以……为基础
- **接続**：[N] + をもとに(して)
- **使用场景**：表素材或依据。
- **例文**：
  1. 実話をもとにした映画。 → 以真实故事为基础的电影。
  2. アンケート結果をもとに分析する。 → 以问卷结果为基础分析。

### 163. ～をはじめ（参见 #127）
- 以……为首。

### 164. ～を中心に(して) / ～を中心とする
- **意味**：以……为中心
- **接続**：[N] + を中心に／を中心とする+N
- **使用场景**：表范围中心。
- **例文**：
  1. 若者を中心に流行している。 → 以年轻人为中心流行。
  2. 東京を中心とする経済圏。 → 以东京为中心的经济圈。

### 165. ～にかけて
- **意味**：到……为止（持续期间）；在……方面（能力）
- **接続**：[N から～N] + にかけて；[N] + にかけては
- **使用场景**：时间/空间范围；或某领域擅长。
- **例文**：
  1. 6月から7月にかけて雨が多い。 → 6 月到 7 月期间多雨。
  2. 料理にかけては彼が一番だ。 → 论做菜数他第一。

### 166. ～にわたって（参见 #77）
- 历经/遍及。

### 167. ～に対して / ～に対する
- **意味**：对于……（对象/对比）
- **接続**：[N] + に対して／に対する + N
- **使用场景**：动作对象或两者对比。
- **例文**：
  1. 質問に対して丁寧に答えた。 → 对于问题礼貌作答。
  2. 兄に対して弟はおとなしい。 → 与哥哥相对弟弟很安静。

### 168. ～について / ～につき / ～につきまして
- **意味**：关于……
- **接続**：[N] + について
- **使用场景**：议论主题。「につき」更正式（兼有"因为"义）。
- **例文**：
  1. 環境問題について発表する。 → 关于环保问题做报告。
  2. 工事中につき通行止め。 → 因施工禁止通行。

### 169. ～にとって
- **意味**：对……来说
- **接続**：[N] + にとって
- **使用场景**：从某立场的评价。
- **例文**：
  1. 私にとって家族が一番大切だ。 → 对我来说家人最重要。
  2. 学生にとって試験はストレスだ。 → 对学生来说考试是压力。

### 170. ～によって / ～により / ～による
- **意味**：① 通过……  ② 由于……  ③ 因……不同  ④ 由……所做（被动）
- **接続**：[N] + によって／により／による
- **使用场景**：万能多义，N2 高频。
- **例文**：
  1. 努力によって成功する。 → 通过努力获得成功。
  2. 地震による被害が大きい。 → 地震造成的损害很大。
  3. 国によって習慣が違う。 → 不同国家习俗不同。
  4. この本は夏目漱石によって書かれた。 → 此书由夏目漱石所著。
